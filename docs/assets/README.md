## Regenerate

Requires Python 3.10+ with `fontTools`, and `rsvg-convert` (librsvg).

```sh
python3 tools/brand/make_assets.py
```

The script downloads the typefaces on first run: Bodoni Moda and IBM Plex Mono, both under the SIL Open Font
License, from [google/fonts](https://github.com/google/fonts). Text is converted to paths, so the SVGs do not
embed or load any font.

## Look

An astronomer's photographic plate: light theme as the glass negative, dark theme as the positive sky, with
emulsion grain. The circled stars are the works of the landing page's example, labelled with their real Wikidata
catalog numbers and joined in the order they were heard. Accent: H-alpha red (`#a91f37` light, `#ff6f82` dark).
